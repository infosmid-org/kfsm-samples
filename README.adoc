This project contains samples for using link:https://github.com/open-jumpco/kfsm[KFSM]

== Build

[source,bash]
----
git clone https://github.com/infosmid-org/kfsm-samples.git
./gradlew assemble
----

=== Build Graal Native Image

[source,bash]
----
mkdir -p ./build/native
native-image -jar ./build/libs/kfsm-samples-fat-LOCAL-SNAPSHOT.jar ./build/native/kfsm-samples -O3 --gc=G1 -march=native
----

_I prefer using link:https://sdkman.io/[sdkman] to switch runtimes while doing this kind of exercise._

== Executing applications

=== Windows
[source,cmd]
----
run.cmd
----

=== *nix
[source,bash]
----
./run.sh
----
